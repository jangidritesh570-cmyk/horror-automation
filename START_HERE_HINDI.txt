UPLOAD STEPS:
1. GitHub par apni horror-automation repository ka main page kholein.
2. Add file > Upload files select karein.
3. Extract kiye hue folder ke andar ki sab files aur `.github` folder select karke drag/drop karein.
4. Commit changes karein.
5. Repository ke main page par expected structure check karein.

SECURITY:
- API keys, Telegram bot token, Google OAuth client_secret.json, refresh token, passwords ya GitHub PAT ko source files mein add na karein.
- Secrets ko sirf GitHub Settings > Secrets and variables > Actions mein save karein.
- YouTube upload pehle UNLISTED rakhein. Public publishing tabhi enable karein jab sample output check ho jaye.
